# 📌 Overview

AI Invoice System is a modern invoice management platform built with **Python**, **Flask**, and **OCR** technologies. It automatically extracts invoice details from uploaded documents, stores the information in a database, and provides a clean dashboard for managing invoices.

The system minimizes manual data entry, improves accuracy, and accelerates invoice processing for businesses of all sizes.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/hariom0014/AI-INVOICE-SYSTEM.git
cd AI-INVOICE-SYSTEM
```

## Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run the Application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
